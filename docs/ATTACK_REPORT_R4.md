Scope: only the round-3 fixes (`d51b8a7..HEAD` in `contracts/`, deployed from `7a74665`). Each finding below has a test in `test/test_attacks_r4.py`, and all 11 tests fail on the current code. The 187 existing tests still pass.

## What held up

- **ETH value:** ETH sent with a token call is counted (`r3_50`). Value sent to the Safe itself is AUTHORIZED, which is correct because nothing leaves. Value attached to a DELEGATECALL is counted as a transfer even though none moves. That is conservative and Low.
- **Switch rules:** only the controller, answering a DEVIATES, can name another proposal. A stranger's appeal cannot name one. Strangers cannot respond in round 2 on a claimed listing. An AS→DEVIATES appeal goes back to CONTESTABLE for the DAO.
- **Round 2:** an unjudged DAO response leaves the appeal's DEVIATES standing, which is consistent with "an unruled appeal leaves the previous ruling". The DAO can run the judge itself.
- **Caps across filings:** `_prior` removes duplicate execution ids, so a refile after expiry is not counted twice under one proposal. A refile is allowed only after `EXPIRED_UNJUDGED`. Same-pair duplicates are refused.
- **Amount phrases:** "not more than" and "no less than" give UNCLEAR, which is conservative. Two amounts on one line or row give UNCLEAR. "Each" is handled. HTML comments and link targets are excluded.
- **Tokens:** an unlisted token named only by its symbol is UNCLEAR, a symbol spoof is not identified, and the `transferFrom` source is checked. A proxy is identified by its listed address, so I found no bypass through proxies.
- **ENS:** names are never resolved at the current block. `read_names_at` refuses blocks that are not finalized. A name repointed to the attacker on an Ethereum-voting space is still dropped (`a21`).
- **Boundaries (`<` vs `<=`):** `appeal` is allowed at `now == contest_deadline` and `finalize` is refused then. `rule` accepts `judged_at == deadline` and `expire` is refused then. Withdrawal is allowed from `withdraw_at + late`, and executions with `block_time <= withdraw_at` block it. The blocking counter is set at the request, and filings and settlements move it symmetrically. Cancelling and requesting again recounts it from `open_checks`.
- **Identity:** standing is keyed by (space, Safe), and a rogue space cannot file the real space's proposals.
- **Ledger:** the invariant held in every money scenario above.
